# PaperClip

面向 iPadOS 26 的本地 PDF 做题与错题整理应用。

## 当前实现

- PDF 文件导入、应用内保存和最近打开记录；
- PDFKit 阅读、缩放和翻页；
- 基于 PencilKit 的逐页独立手写层；
- 画笔、橡皮擦、撤销、重做和手写层显隐；
- 不写入正式答案层的临时透明草稿板；
- PDF 页面矩形框选与错题截图生成；
- 使用豆包图片理解模型识别题目，确认文字后可选择豆包或 DeepSeek V4 Pro 生成结构化解析；
- SwiftData 错题卡编辑、筛选和删除；
- 每页 1/2/4 题的 A4 练习版、复习版 PDF；
- 系统分享菜单导出。
- SwiftData 单词集、单词编辑、搜索和删除；
- TXT 文本导入，支持 Tab、竖线、等号、冒号、横线、逗号、双行、Markdown 表格和 JSON 内容；
- 标准 FSRS-6 双向记忆调度：21 参数、目标保持率、短期学习/重学步进、间隔扰动和完整复习日志；
- 闪卡、混合学习、可配置测验、系统发音和 Apple Pencil 手写拼写。

## 开发环境

- Xcode 26.5
- Swift 6
- 最低系统版本 iPadOS 26.0
- 仅支持 iPad

打开 `PaperClip.xcodeproj`，选择 iPadOS 26 模拟器或真机运行。

## AI 解析配置

在应用的“设置 → AI 解析设置”中填写火山方舟 API Key。豆包通过接入点
`ep-20260620182757-zwqg9` 识别题目；学生确认识别文字后，可选择豆包或
DeepSeek V4 Pro（接入点 `ep-20260620195700-bp4j9`）完成解析。API Key
仅保存在设备 Keychain 中。题目图片只发送给豆包，DeepSeek 只接收确认后的
题目文字和识别元数据。
