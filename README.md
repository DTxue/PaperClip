# PaperClip

面向 iPadOS 26 的本地学习应用。

## 当前实现

- 独立错题库，支持文字、相册、文件和文稿扫描录入；
- 按状态、学科和关键词整理错题，支持收藏、归档与最近删除；
- 基于 PencilKit 的错题重做、答案揭示、结果记录和 1/3/7 天复习安排；
- PDF 文件导入、应用内保存和最近打开记录；
- PDFKit 阅读、缩放和翻页；
- 基于 PencilKit 的逐页独立手写层；
- 画笔、橡皮擦、撤销、重做和手写层显隐；
- 不写入正式答案层的临时透明草稿板；
- 系统分享菜单导出。
- SwiftData 单词集、单词编辑、搜索和删除；
- TXT 文本导入，支持 Tab、竖线、等号、冒号、横线、逗号、双行、Markdown 表格和 JSON 内容；
- 标准 FSRS-6 双向记忆调度：21 参数、目标保持率、短期学习/重学步进、间隔扰动和完整复习日志；
- 闪卡、混合学习、可配置测验、系统发音和 Apple Pencil 手写拼写。

## 开发环境

- Xcode 26.5
- Swift 6
- 最低系统版本 iPadOS 26.0
- 仅支持 iPad

打开 `PaperClip.xcodeproj`，选择 iPadOS 26 模拟器或真机运行。

## AI 解析配置

在应用的“设置 → AI 解析设置”中填写所需 API Key。密钥仅保存在设备 Keychain 中。
