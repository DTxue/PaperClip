# PaperClip iPad 操作流程验收

本清单用于验证 PDFKit、PencilKit、SwiftUI 和真实 Apple Pencil 组合交互。
自动化测试不能替代这里的真机步骤。

## 数据安全前置条件

- [ ] 在当前真机版本进入“设置 → 数据备份”，安排并完成一次整库备份。
- [ ] 将备份保存到 Files、iCloud Drive 或 Mac，不能只保留在 App 临时目录。
- [ ] 仅允许覆盖安装；不得卸载 PaperClip，不得清除 App 数据。
- [ ] 覆盖安装后先确认历史 PDF、词集、考试记录和笔迹仍可打开，再创建新测试数据。

## 已完成的模拟器验收

环境：iPad Air 13-inch (M4) 模拟器，iOS 26.5。

- [x] 保留历史数据覆盖安装后冷启动，无数据库错误或恢复阻塞弹窗。
- [x] 历史 PDF 与历史词集可见，数量未因升级丢失。
- [x] 从考试记录打开 PDF 并继续考试的流程可达。
- [x] 考试计时、PKToolPicker、保存并退出、继续最近考试、考试记录可用。
- [x] 指针拖动 PDF 会滚动/缩放页面，不会产生 Pencil 笔迹。
- [x] 写作空状态“生成写作题”主按钮可聚焦，并能打开生成表单。
- [x] 词集、词生文、统计、数据备份、日记和知识库入口可达。
- [x] 顶部“错题库”位于“日记”之后。
- [x] iOS Simulator 与 iOS Device SDK 完整构建成功。

## 真机 Apple Pencil / 手指验收

每一步完成后记录日期、设备和结果；失败时不要卸载 App。

### 1. 冷启动与历史数据

- [ ] 覆盖安装后启动 App，无数据库不可用、恢复失败或临时模式提示。
- [ ] 随机打开一份历史 PDF、一条考试记录和一个词集，确认内容完整。

预期：升级不改变源 PDF、历史笔迹、考试状态或词汇学习记录。

### 2. PDF 阅读与书写分流

- [ ] 用单指滚动页面，用双指缩放 PDF。
- [ ] 用 Apple Pencil 在同一页面书写。
- [ ] 再用手指滚动，确认手指不会留下笔迹。
- [ ] 使用 PencilKit 撤销、重做、橡皮擦和颜色切换。

预期：手指只负责浏览，Apple Pencil 只负责书写；系统 `PKToolPicker` 行为正常。

### 3. 切页、后台与退出保存

- [ ] 写下可识别标记后切换到另一页，再返回原页。
- [ ] 将 App 切到后台后重新进入。
- [ ] 选择“保存并退出”，再从“继续最近考试”恢复。

预期：每次切换前先保存 pending drawing；恢复后笔迹位置、缩放和考试记录绑定正确。

### 4. 交卷保护

- [ ] 在考试页面补充一笔后立即点击“交卷”。
- [ ] 完成交卷确认并进入后续批阅流程。

预期：最后一笔先保存；保存失败时不得改变考试状态，也不得进入已交卷状态。

### 5. 草稿板

- [ ] 打开浮动草稿板，用 Apple Pencil 书写，用手指移动控制点或滚动画布。

预期：源 PDF 不被修改；草内容不写入正式答题图层。

### 6. 作文与词汇手写

- [ ] 新建作文草稿，用 Apple Pencil 书写，退出后重新进入。
- [ ] 进入词汇手写测试，书写一个答案并切换题目。

预期：作文和词汇画布均使用 Pencil-only 策略；切换或退出不会丢失当前笔迹。

### 7. 错题库录入与重做

- [ ] 依次进入“全部错题、待重做、收藏、待整理、学习中、已掌握、已归档”，确认均先显示全部学科文件夹和各自错题数量，再从学科进入列表。
- [ ] 从相册选择一张包含多道题的竖拍图片，拖动选框和四角控制点，只框选其中一道题后保存。
- [ ] 首次点击“扫描文档录入”并允许相机权限，确认授权完成后直接进入扫描器，无需退出后再次点击。
- [ ] 文档扫描两页内容，确认两页会依次进入手动框选；取消其中一页不会阻塞下一页。
- [ ] 确认录入页只有“相册”和“扫描文档”入口，未完成任意一次框选时不能保存新错题。
- [ ] 点击顶部已录入图片，确认图片不会消失；点击图片右上角删除按钮才会移除。
- [ ] 分别录入横向长图和竖向长图，确认录入、详情和重做页面完整等比显示，不裁掉题目内容。
- [ ] 点击“识别题目并整理”，确认豆包只转写题目且识别文本可以修改。
- [ ] 使用包含 `$x^2$`、`$\frac{a}{b}$` 和独立公式的题目，断网后确认录入预览、列表、详情及重做页均正常排版公式。
- [ ] 选择年级、学期和多个错误原因标签；确认录入页不再出现答案与解析。
- [ ] 检查未选中的错误原因 Tag，确认文字前没有透明图标造成的空位；选中后勾选显示在文字后方且文字不换行。
- [ ] 完成题目文字整理后确认错题进入“学习中”，并显示下次重做日期。
- [ ] 使用 Apple Pencil 完成一次重做，并分别测试“做对了”和“还不会”。
- [ ] 将错题移入最近删除、恢复，再新建测试错题并永久删除。

预期：相册原图和扫描源不被改写；保存图片只包含框选区域；每次笔迹与结果独立保存；删除不会影响 PDF、词汇、日记或写作数据。

## 失败处理

- 不得卸载 App。
- 先记录具体入口、页面、操作顺序和是否可稳定复现。
- 优先 Stop/Run、重启 Xcode、重启调试服务、拔插 USB 或重启 iPad。
- 涉及恢复、迁移或覆盖安装前，重新确认整库备份仍可访问。
